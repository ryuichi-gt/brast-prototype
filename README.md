# BRAST — Brand Strategy OS（プロトタイプ）

> 「ブランドの憲法に統治された、自律ブランドストラテジスト」。AIが毎週フルオートで戦略を作り切り、
> 根拠から結論まで辿れる形でプレゼンしてくる。人間は上司としてレビュー → 承認 or 差し戻しをするだけ。

Phase 1 フロントエンドのプロトタイプ。すべてダミーJSON駆動で、取得は `src/lib/api.ts` の
fetch 層に分離（Phase 2 で実バックエンドに差し替え）。確定仕様は [`CLAUDE.md`](./CLAUDE.md)（v2）、
詳細は `reference/`（`strategy-logic.md`＝戦略導出ロジック／推論グラフのノード定義、`ux-flow.md`＝画面の正）。

## 技術スタック

- **Next.js 14 (App Router) + TypeScript + Tailwind CSS**
- デザイントークンは `src/app/globals.css`（mockup の配色・タイポを踏襲）。teal=AI／amber=人間。
- データはダミー（`src/data/`）。取得は `src/lib/api.ts` に集約。`localStorage` 不使用。

## セットアップ

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 本番ビルド（型チェック + lint 込み）
```

## 3本柱（v2 で実装）

1. **ブランド運用ルール（ガバナンス層・柱1）** — `ブランド運用ルール` 画面。出面（チャネル）戦略
   ＋ガードレール（トーン／薬機法・景表法／主張の制約）＋KPI を、**AIが提案 → 人間が承認・編集**。
   各ルールに 提案中／承認済み／編集中 と改訂履歴。以降の戦略・コンテンツ・外部指示の制約源。
2. **グラスボックス推論（柱2・キーストーン）** — 週次ブリーフィング上段の **推論グラフ S1〜S6**
   （strategy-logic.md）。各ステージをタップ→「入力した根拠／操作（適用ルール・重み）／結論」。
   スライドの主張 → 戦略ベット(S4) ← 機会(S2) ← 信号(S1の実データ) へドリルダウン。
   差し戻しは推論グラフの該当ノードへ遡り、下流だけ再実行。
3. **閉じたループ（柱3）** — `実行・結果` 画面（配信進行＋週次結果リーチ/CV/期待値到達＋Slack日次
   レポート＋人間の到達/未達評価）。戦略アーカイブに結果表示。推論グラフ S1/S5 →
   トレンド／ナレッジ／ルール画面へジャンプ（「存在する」→「根拠として辿れる」）。

## 主な画面

- **週次ブリーフィング**: 推論グラフ（S1〜S6）＋ 縦並び7スライド ＋ AIチャット（操作面）＋ 承認フッター。
- **実行・結果**: 配信状況／週次結果／Slack日次レポート／期待値評価。
- **戦略アーカイブ**: 週次戦略シート＋実行結果（CV・期待値）。
- **ブランド運用ルール**: 出面戦略／ガードレール／KPI／改訂履歴（AI提案→承認）。
- **ブランドナレッジ**: 差分検知（最新／更新候補）。
- **トレンド・レーダー**: ライブ信号＋**関連度の理由（概念マッチ）と、除外した無関連の理由**。
- **コンテンツ**: 配信予定／配信済み。旧版vs新版の並列提示。タイトルタップで記事リーダー。
- **記事リーダー**: 本文・スコア・4体レビュー内訳・根拠ソース（実URL）・生成元ベットへの逆リンク・
  **インライン修正チャット＋ブランド押し返し**（規範違反指示は「ルールXに反します。実行しますか？」）。
- **チャネル／エージェント**: 一元管理・役割可視化／オーケストレーション閲覧（編集不可）。

操作面は AIチャット中心（"AI部下"への指示）、消費面はデッキ/各画面。teal=AI・amber=人間を全画面で厳守。

## 数値・推論の扱い（重要）

- スコア・リーチ・関連度・opportunity 重みは実測値ではなく**現実的な推定値／叩き台**（Phase 1 規約）。
  しきい値は `src/data/config.ts` に集約：スコアゲート=**90（確定）**、relevance=60・opportunity 重み
  0.35/0.30/0.20/0.15 は **要確認**（strategy-logic.md §8）。
- 推論トレースは JRC を手書き、他テナントは既存スライドから自動導出（`src/lib/reasoning.ts`）。
